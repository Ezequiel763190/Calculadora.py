CALCULADORA PYTHON

A Calculadora Python é um projeto desenvolvido totalmente em Python com o objetivo de simular uma calculadora funcional diretamente no terminal. O sistema permite ao usuário realizar diferentes operações matemáticas de forma simples e interativa, além de contar com tratamento de erros para garantir uma melhor experiência de uso.

Objetivo do Projeto:

Esse projeto foi desenvolvido com o propósito de praticar e aprimorar conhecimentos em Python e lógica de programação. Durante o desenvolvimento foram utilizados conceitos como:

- Estruturas condicionais;
- Laços de repetição;
- Funções;
- Tratamento de exceções (try/except);
- Bibliotecas nativas do Python;
- Manipulação de entradas do usuário;
- Organização de menus interativos;
- Validação de dados.

Funcionalidades:

- Soma (+);
- Subtração (-);
- Multiplicação (*);
- Divisão (/);
- Potenciação (**);
- Resto da divisão (%);
- Cálculo de raiz quadrada;
- Limpeza da tela do terminal;
- Tratamento de divisão por zero;
- Tratamento de entradas inválidas;
- Repetição contínua de operações até o encerramento pelo usuário.

## Tecnologias

* Python;
* Biblioteca Math;
* Biblioteca OS;
* Terminal / Console;
* Lógica de Programação.

Sobre o Projeto:

A Calculadora Python foi criada com foco em aprendizado e prática dos conceitos fundamentais da programação. O projeto permitiu aplicar conhecimentos importantes de Python, como estruturas de decisão, repetição, funções e tratamento de erros, além de trabalhar a interação com o usuário por meio do terminal.

Durante o desenvolvimento, também foram exploradas bibliotecas nativas do Python, como Math para operações matemáticas e OS para manipulação do terminal. O projeto contribuiu para o aprimoramento da organização de código, da lógica de programação e da criação de aplicações interativas.
